# Домашнее задание №1 — Third Person

Проект на Unreal Engine 5.8.1 на основе Third Person Template. Создан C++ класс персонажа, унаследованный от ACharacter, и назначен родителем BP_ThirdPersonCharacter. Через Enhanced Input реализованы спринт и взаимодействие. При взаимодействии C++ вызывает динамический multicast-делегат, а Blueprint выводит сообщение «Interaction triggered!».

Спринт увеличивает скорость персонажа и переключает Animation Blueprint в состояние Sprint по переменной bIsSprinting. Дополнительно реализована выносливость на C++: она расходуется во время спринта, восстанавливается вне спринта и отображается на экране. При истощении спринт прекращается даже при удержании клавиши; для повторного спринта нужно восстановить запас и нажать Shift заново.

## Управление

| Клавиша | Действие |
| --- | --- |
| W, A, S, D | Движение |
| Мышь | Вращение камеры |
| Space | Прыжок |
| Left Shift, удерживать | Спринт |
| E | Взаимодействие |
